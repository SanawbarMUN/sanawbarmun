SanawbarMUN free editor

1. Open editor.html in your browser (or on the same GitHub Pages website).
2. Change conference text, committee chairs, resource links, dates and basic appearance.
3. Click Download updated content.js.
4. Go to your GitHub repository and update the existing content.js file with the downloaded content (open file -> pencil -> replace with downloaded contents -> Commit changes).
5. Wait for GitHub Pages to deploy.

Photos: upload image files to an assets folder on GitHub, then paste assets/your-photo.jpg into the photo field.

IMPORTANT: editor.html does not have a login, cannot publish automatically and is not a secure backend. It does not save changes to GitHub directly. Anyone who opens it can edit their own local copy, but cannot change your live website without GitHub write permissions. Do not use it for private student information.
