To publish: Click “Download updated content.js”, open your GitHub repository, choose content.js → ⋯ → Upload files (or Add file → Upload files in the repository), upload the downloaded replacement and choose Replace if prompted, then Commit changes. The simplest reliable method is to open the GitHub file, click edit, replace its text with the downloaded file's text, and commit. Do not upload the admin page or editor to GitHub unless you understand that it is a public tool, not a password-protected admin panel.
